01 — the brief

One integrated problem, two source documents

PFEC's Vendor Requirements brief specifies the voice/telephony contract; the BRD specifies the Zoho CRM data model and business rules. Taken together, this isn't "buy a calling bot" — it's a CRM-orchestrated conversation platform with a hard compliance rule (no Zapier) and a hard quality bar (Bangla).

Bangla quality

Most global platforms treat Bengali as an afterthought; Indic specialists nail the accent but aren't built for enterprise CRM orchestration. This is PFEC's own pilot go/no-go gate.

Zoho, not Zapier

The BRD explicitly bans iPaaS in production. That write-back logic has to be owned and built by a custom middleware, not bought as a plug-in.

Two regions, two journeys

Offshore batch/real-time calling and Onshore Education vs. Migration flows need different scripts, driven by live Zoho CRM context.

02 — architecture

A composable, best-of-breed stack — not one monolith

Each layer is independently swappable, because the two hardest requirements — authentic Bangla speech and a Zapier-free Zoho contract — are best solved by different specialists.

03 — feasibility study

Six platforms evaluated against PFEC's must-haves

Each card shows the actual stack shape for that option — composable boxes that plug together, or one closed/bundled box.

Vapi BEST FIT

  • $0.05/min platform fee + pass-through (all-in ~$0.13–$0.31/min)
  • Usage-based concurrency, deep tooling ecosystem
  • Primary recommendation

Retell AI STRONG ALT

  • $0.055/min infra + pass-through, telephony waived with BYO-SIP
  • 20 concurrent calls included free
  • Strong alternative / fallback

Bland.ai BANGLA RISK

  • Bengali support unconfirmed in public docs
  • Closed speech stack — can't swap in a Bangla specialist
  • Workable fallback, not the pilot bet

Bolna AI COST OPTION

  • Native Bengali, purpose-built for Indic code-switching
  • India-first telephony — BD BYO-SIP needs confirmation
  • Attractive cost, worth a pilot slot

Gnani.ai FALLBACK

  • Native Bengali, strong BFSI enterprise track record
  • Enterprise / sales-led onboarding
  • Good fallback if Vapi/Retell underperform

Full Custom Build PHASE 3

  • Full control, zero vendor lock-in
  • 8–16 weeks, $35,000–$150,000+ before Zoho work
  • Optional, once volume justifies it
04 — implementation

Implementation runbook — what actually gets built

The concrete build steps behind the Phase 1 roadmap.

1

Zoho CRM fields & stages

Custom fields/picklists for the 11-stage model; campaign, UTM, destination, branch, enquiry-type fields

2

Workflow Rule + webhook

Instant Webhook or Deluge function fires on stage-eligible update — no Zapier

3

Middleware: webhook receiver

Receives Zoho's trigger and the voice platform's end-of-call webhook; maps outcome to stage

4

Middleware: retry scheduler

Seven-attempt / five-day retry logic with configurable calling windows

5

Voice platform + BYO-SIP

Assistant/script config in Vapi or Retell; BYO-SIP trunk connected

6

Speech A/B + test calls

Azure bn-BD vs Sarvam vs Deepgram, scored by native-speaker review
